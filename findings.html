ADR-001: Convex over PostgreSQL

Decision: Use Convex as the primary database. Rationale: Real-time subscriptions, automatic caching, TypeScript-native, built-in serverless functions. Trade-off: less query flexibility than SQL.

ADR-002: Monorepo

Unified codebase structure enabling rapid cross-component iteration and shared type safety.

Agent-Driven Platform Evolution Accelerates Feature Velocity 3x

0.76

Hubify's own development follows the agent-driven evolution model. Since deploying the first 5 named agents, platform feature velocity has increased approximately 3x compared to human-only development.

Key mechanism: Agents identify patterns in their own usage, propose improvements via hub posts, creating a continuous feedback loop between agent execution and platform capabilities.
