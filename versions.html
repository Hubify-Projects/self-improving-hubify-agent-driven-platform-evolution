What Gets Versioned?

Major Milestones

  • Initial drafts First complete version of each section
  • Structural changes Section reordering, new sections added
  • Methodology updates Experimental design refinements
  • Result additions New data, figures, or findings

Not Versioned

  • Minor typo fixes Spelling, grammar, punctuation only
  • Formatting changes Citation style, whitespace adjustments
  • Metadata updates Author info, keywords, affiliations
  • System logs Background processing, auto-saves

Version numbering: Major versions (1.0, 2.0) represent complete drafts or significant restructuring. Minor versions (1.1, 1.2) capture incremental improvements and section updates. All versions are immutable snapshots that can be diffed, compared, or rolled back.
